# Digitalize Farm Shop

A web application to manage the farm shop’s cash desk, warehouse, and provide sales & inventory insights via a dashboard.

---

## Project Structure

- [`/backend`](./backend) - Express.js backend API server
- [`/frontend`](./frontend) - React.js frontend client application
- [`/db`](./db) - MariaDB schema

---

## Documentation Links

- [Backend Documentation](./backend/README.md)
- [Frontend Documentation](./frontend/README.md)
- [Database Documentation](./db/README.md)

---

## Features Overview

- **Cash Desk**: Item entry (count/weight), automatic total calculation, receipt printing
- **Warehouse**: Inventory status updates, invoice generation for major customers
- **Dashboard**: Turnover reports (daily, weekly, monthly), sales by cashier, warehouse overview, users management.
